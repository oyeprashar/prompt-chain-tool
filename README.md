# Prompt Chain Tool

COMS 6998E Week 8 assignment: manage and execute multi-step AI prompt chains.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Planned features

- Supabase Google authentication with superadmin-only access
- Create, edit, delete, and reorder prompt chains and steps
- Run chained AI prompts and save generated output
- Media history and light/dark/system themes

## Security

Never commit secrets or `.env.local`.
